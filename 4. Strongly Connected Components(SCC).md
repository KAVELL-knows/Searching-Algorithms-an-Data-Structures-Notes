# Strongly Connected Components

A **Strongly Connected Component (SCC)** is a maximal set of vertices in a directed graph such that **every vertex is reachable from every other vertex** in the component.

For vertices `u` and `v` in the same SCC:

```text
u → v
```

and

```text
v → u
```

must both be possible through directed paths.

### Example

```text
A → B
↑   ↓
└── C
```

`A`, `B`, and `C` form one SCC because every vertex can reach every other vertex.

SCCs divide the vertices of a directed graph into groups based on **mutual reachability**.

---

# SCC Meta-Graph

We can treat each SCC as a single vertex.

The resulting graph is called the **meta-graph** (or component graph).

### Important Property

> **The SCC meta-graph is always a DAG.**

If the SCCs formed a directed cycle, then the SCCs would be mutually reachable and could be combined into one larger SCC.

Therefore:

```text
Directed Graph
      ↓
   SCCs
      ↓
Compress each SCC
      ↓
   Meta-Graph
      ↓
     DAG
```

---

# Kosaraju's Algorithm

**Kosaraju's algorithm** finds all SCCs in a directed graph using **two passes of DFS**.

### Running Time

```text
O(V + E)
```

where:

* `V` = number of vertices
* `E` = number of edges

---

## Step 1 — Reverse the Graph

Reverse every edge in the graph.

For example:

```text
u → v
```

becomes:

```text
u ← v
```

The resulting graph is called the **reversed graph** or `Gᵀ`.

---

## Step 2 — DFS on the Reversed Graph

Run DFS on the reversed graph.

Record the **finishing time** of every vertex.

A vertex's finishing time is recorded when DFS has finished exploring all of its outgoing edges.

Only the **relative order** of the finishing times matters.

---

## Step 3 — DFS on the Original Graph

Return to the **original graph**.

Process vertices in **decreasing order of their finishing times** from Step 2.

For each unvisited vertex:

1. Start a DFS.
2. Mark all vertices reached by that DFS as part of the same SCC.
3. Continue with the next unvisited vertex.

Each DFS in this second pass discovers **exactly one SCC**.

---

# Kosaraju's Algorithm — Summary

```text
1. Reverse all edges.
2. Run DFS on the reversed graph.
3. Record finishing times.
4. Return to the original graph.
5. Process vertices in decreasing finishing-time order.
6. Run DFS from each unvisited vertex.
7. Each DFS tree gives one SCC.
```

---

# Why Does It Work?

The SCCs can be viewed as vertices in a **DAG**.

The first DFS pass on the reversed graph gives finishing times that order the SCCs correctly for the second pass.

The vertex with the **largest finishing time** belongs to a **sink SCC** in the original graph.

A sink SCC has **no outgoing edges to another SCC**.

Therefore, when the second DFS starts from that SCC, it cannot leave the SCC and reach another component.

So the DFS discovers **exactly that SCC**.

After marking it explored, the process repeats on the remaining graph.

This effectively **peels off the SCCs one at a time**.

---

# Key Lemma

Suppose two SCCs have an edge:

```text
C₁ → C₂
```

In the reversed graph, the finishing times satisfy:

```text
max finishing time(C₂)
        >
max finishing time(C₁)
```

This ensures that the second DFS pass processes the SCCs in the correct order.

---

# Correctness

The correctness of Kosaraju's algorithm follows from:

* SCCs forming a **DAG** when compressed into the meta-graph.
* The first DFS pass producing the required finishing-time order.
* The largest finishing time belonging to a **sink SCC**.
* A DFS started at a sink SCC being unable to leave that SCC.
* Removing discovered SCCs and repeating the process.

Thus, every SCC is found exactly once.

---

# Key Takeaways

* An **SCC** is a maximal set of mutually reachable vertices.
* SCCs partition a directed graph based on mutual reachability.
* The **SCC meta-graph is always a DAG**.
* **Kosaraju's algorithm** uses two DFS passes.
* First pass: DFS on the **reversed graph** and record finishing times.
* Second pass: DFS on the **original graph** in decreasing finishing-time order.
* Each DFS in the second pass finds **one SCC**.
* Running time: **O(V + E)**.
